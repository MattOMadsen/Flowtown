# Flowtown

**Cozy browser traffic management game**  
Tegn veje mellem distrikter og hold byen kørende. Fungerer på både mobil og PC.

## Sådan spiller du
1. **Tegn**-mode: Tegn veje mellem distrikterne (endepunkter snapper automatisk).
2. **Slet**-mode: Tryk på en vej for at fjerne den.
3. Nå progressive mål (20 → 40 → 70 …) for at stige i niveau.
4. Rekorden gemmes automatisk i browseren.

## Features
- Frihånds-tegning + endpoint snapping
- Erase mode
- Density-baseret jam (farve på veje)
- Arrival particles + goal celebration
- Progressive mål + progress bar
- localStorage highscore (all-time rekord)
- Session best + flow %
- Touch + mouse

## Tech
Vanilla JS + Canvas + Tailwind (CDN)
